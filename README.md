# Night City: Underworld

**A planned Cyberpunk 2077 mod for a living, persistent criminal underworld.**

Gangs compete over territory, resources and technologies, NPCs develop relationships and remember encounters, and V's actions change the balance of power. The goal is systemic emergent gameplay rather than randomly spawned firefights.

## Planned features
- **Factions:** reputation, relationships, rivalries, alliances, gang wars, policing, territory and strategic decisions.
- **Nemesis NPCs:** hierarchy, friends and enemies, survival, flight/surrender, nonlethal encounters, injury, recovery, cyberware replacement and retaliation.
- **Intelligence:** witnesses, informants, hacking risk, Kiroshi scanner and connected underworld dossier.
- **Economy:** faction vendors, reputation discounts, independent/corporate/underground ripperdocs, illegal and experimental cyberware.
- **Logistics:** discoverable illicit shipments that expose underground suppliers, clinics and new opportunities.

## Status
**Design / Phase 0. No working gameplay mod has been released or verified.** Engine integration, version compatibility and feasibility probes are outstanding.
